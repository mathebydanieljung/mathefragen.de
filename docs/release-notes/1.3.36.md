# Version 1.3.36

## 🔧 Wartung & Sicherheit

- **Schlankeres Docker-Image**: Poetry ist nicht mehr im Produktions-Image, die Python-Pakete belegen nun 135 MB statt 205 MB.
- **Automatische Tests**: Die Testsuite läuft jetzt bei jedem Push und Pull Request auf GitHub Actions.
- **Zuverlässige Sicherheitswarnungen**: Der Abhängigkeitsgraph wird aus der CI an GitHub übermittelt, Dependabot-Warnungen spiegeln wieder den tatsächlichen Stand.
