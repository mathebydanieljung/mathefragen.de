# Version 1.3.32

## 🛡️ Neu für Moderator:innen & Admins

Fragen lassen sich jetzt **direkt auf der Fragen-Seite** moderieren — ohne Umweg über den Adminbereich. Auf jeder Frage erscheint für Berechtigte ein kleines Moderations-Panel:

- **Verstecken / Einblenden** — eine Frage mit einem Klick öffentlich unsichtbar schalten oder wieder einblenden (reversibel).
- **Löschen** — unnötige oder Spam-Fragen direkt entfernen (mit Sicherheitsabfrage).

Sichtbar für Admins sowie Moderator:innen mit entsprechendem Badge.
